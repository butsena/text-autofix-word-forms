# Формы сложных слов

Public-репозиторий для плагина **Text Autofix** (Циан).

Здесь пары слов, у которых **оба варианта допустимы**, и плагин просит человека выбрать  
(не правит автоматически). Примеры: `ищите` / `ищете`, `все` / `всё`.

Плагин при запуске скачивает `ambiguous-form-choices.txt` с GitHub.  
Пересобирать плагин после правок **не нужно**.

---

## Файл

| Файл | Назначение |
|---|---|
| `ambiguous-form-choices.txt` | Пары форм + подсказка для редактора в UI |

## Формат строки

```
форма1 - форма2 - подсказка
```

Пример:

```
# id: cian-choice-ishchite-ishchete
ищите - ищете - что делаете? | ищете квартиру целую вечность; что делайте? | повелеваю: ищите квартиру только на Циане!

# id: cian-choice-vse-vsyo
все - всё - по редполитике Циана мы пишем ё там, где это требуется
```

Правила:

1. Три части через ` - ` (пробел-дефис-пробел): две формы и подсказка.
2. Несколько пунктов подсказки разделяйте `;`.
3. В пункте можно писать `вопрос | пример`.
4. Строка `# id: ...` перед парой — необязательный стабильный идентификатор.
5. Пустые строки и обычные комментарии `#` игнорируются.
6. Не меняйте имя файла.

---

## Как править редактору

1. Откройте:  
   https://github.com/butsena/text-autofix-word-forms/blob/main/ambiguous-form-choices.txt
2. Нажмите карандаш (**Edit**).
3. Добавьте пару или поправьте подсказку.
4. **Commit changes** → в `main`.

Если нет доступа на запись — оформите Pull Request.

---

## Как это выглядит в плагине

В макете плагин покажет блок **«Выберите вариант»** с двумя кнопками форм.  
Подсказка из третьей колонки помогает выбрать правильный смысл.
